# Cypress JS Framework

A project presenting an E2E testing framework using Cypress and JavaScript.

## Description

This project contains a sample structure of an E2E test framework based on Cypress. It allows for easy writing, running, and management of automated tests.

The framework is used to test the following demo application: [gad-gui-api-demo](https://github.com/jaktestowac/gad-gui-api-demo/tree/main).

## Installation

Install dependencies:

```bash
npm install
```

## Running Tests

To run tests in interactive mode:

```bash
npm run cypress:open
```

## Project Structure

- `cypress/e2e/` – directory with E2E tests
- `cypress.config.js` – Cypress configuration file
- `package.json` – project configuration and dependencies
